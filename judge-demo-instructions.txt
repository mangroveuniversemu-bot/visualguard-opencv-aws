VISUALGUARD - JUDGE DEMONSTRATION GUIDE

The shortest walkthrough
1. Open the local application. Select the clear paired sample and inspect: REVIEW.
2. Select the side-only red indicator sample and inspect: STOP / HOLD_AUTOMATION.
3. Select the occluded front-view sample and inspect: REQUEST_VIEW.
4. Supply a usable replacement pair with new capture IDs and inspect again: REVIEW.
5. Open the saved AWS evidence. Review health, alarm, clear and empty-view results from the recorded deployment.

What each step demonstrates
The input is a front-and-side synthetic image pair. Pixel-based quality and candidate detection change the planned next step. Human resubmission is the demonstrated follow-up; no camera trigger or equipment command is executed. The local replay viewer reads saved cloud evidence and makes no AWS requests.

Run locally from the source archive
Use Python 3.12 and a writable project directory.
python -m pip install -r requirements-vision.txt pytest==9.0.2
python -m pytest -q
python -m service.app --host 127.0.0.1 --port 8080
Open http://127.0.0.1:8080/ in the same machine's browser.

For the supplied Windows review candidate
Run from a normal local PowerShell terminal in the extracted project directory:
powershell -File ops/run_windows.ps1 -Action Test -Python python
powershell -File ops/run_windows.ps1 -Action Serve -Python python -Port 8766
Open http://127.0.0.1:8766/.
The helper places SQLite and temporary files under .local and restores the environment when it exits.

python ops/verify_aws_recording.py
python ops/verify_judge_evidence_index.py
